# Deepwoken Smart Aid — Roadmap

Умное руководство по Deepwoken в духе dnd.su: таланты, квесты, острова, советы новичкам, конструктор билдов и помощник.

## Решения
- **Стек:** HTML, CSS, JS (без сборщика), хостинг Spaceweb, тариф «Взлёт» (PHP и MySQL доступны, 10 ГБ диска).
- **Стиль:** «Фолиант Глубин» (книга: кожа, пергамент, тиснение) с элементами «гримуара» (тёмный фон, свечение рун, цвета школ). На мобильных книга становится одной страницей.
- **Язык:** русский в приоритете, английский вторым. Структура с файлами переводов с первого дня. Названия талантов показываем как «описание на русском + оригинальное английское имя».
- **Помощник:** гибрид. Сначала поиск и правила в браузере, затем LLM-чат через PHP-прокси.
- **Данные:** MediaWiki API Fandom → JSON. Лицензия CC BY-SA: указываем источник и лицензию.
- **Приоритет:** каталог талантов → билдер → чат.

## Этапы

### Этап 0. Фундамент
- Структура проекта: `/css`, `/js`, `/data`, `/pages`, `/scripts`.
- Дизайн-система: палитра, шрифты, обложка, закладки-разделы, карточки, рамки, цвета школ.
- Адаптивная вёрстка, переключатель RU/EN, лёгкий роутер.
- **Результат:** каркас сайта в нужном стиле.

### Этап 1. Данные
- Скрипт: MediaWiki API Fandom → нормализованные JSON (таланты, оружие, мантры, острова, квесты, NPC).
- Схема данных, проверка целостности, ссылки между сущностями.
- Страница об источниках и лицензии.
- **Результат:** база в `/data`, обновляется одной командой.

### Этап 2. Каталог талантов (MVP, первый релиз)
- Поиск, фильтры, карточка таланта, связанные таланты.
- Русские описания добавляем постепенно, начиная с популярных.

### Этап 3. Острова, квесты, справочник
- Острова (NPC, боссы, лут), квесты с пошаговым прохождением, оружие, мантры, мутации, расы.
- Сквозные ссылки и общий поиск.

### Этап 4. Раздел для новичков
- Свои гайды: первые часы, ошибки, терминология, стартовые билды. Параллельно этапам 2–3.

### Этап 5. Конструктор билдов
- Статы, проверка требований талантов, подсчёт очков, сохранение и экспорт ссылкой.
- Готовые архетипы. Это ядро помощника.

### Этап 6. Помощник без LLM
- Локальный поиск по базе, подбор билда по вопросам.

### Этап 7. LLM-чат
- PHP-прокси на Spaceweb: ключ на сервере, лимиты запросов, ответы по найденным фрагментам базы со ссылками на источник.

### Этап 8. Полировка и деплой
- Анимации, SEO, производительность, деплой, автообновление данных, английская версия.

## Порядок работы
Этап за этапом: после каждого показываем результат и только потом идём дальше. Релиз возможен после этапа 2.
